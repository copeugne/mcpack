# BetterEnd ruin block-layout views

Generated by tools/view_item8_betterend_ruins.py at 3b14c8d from the frozen
BetterEnd-21.0.31.jar archive through retained_sources and the existing NBT decoder.
Archive SHA-256: dd883e2f91fa7ee8a0594dc3844de38bf3e550d91ff1247b2801808904fd013a.

These six SVG sheets show the 35 already-selected ruin templates. Each occupied
block position is shown as a cube; stairs, fences, chains and other partial
models are not reproduced. Green only hints at names containing leaves, moss,
vine, grass or flower; it is not a vegetation classification (mossy wood also
matches). SVG tooltips retain exact block IDs and coordinates. Views rescale
each template independently. Do not infer relative sizes from screen scale,
hidden interiors from one projection, or generated-world placement from a view.

The existing template catalog and configured-list tests remain the authority
for material, NBT, identity and selection. These diagrams support manual layout
comparison; they do not automatically assign families or replace world evidence.

```sh
uv run -m tools.view_item8_betterend_ruins --output evidence/raw/item8/betterend-ruin-views-r2
```

The six SVG outputs reproduced byte for byte against this directory before this
README was added. For visual inspection, use the installed converter, for example:

```sh
convert evidence/raw/item8/betterend-ruin-views-r2/chorus_forest.svg evidence/raw/item8/betterend-ruin-views-r2/chorus_forest.png
```
