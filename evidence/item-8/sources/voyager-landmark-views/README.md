non-cathedral Voyager decisions from the hash-verified retained
MoogsVoyagerStructures-1.21-5.0.11.jar archive. All five sheets were manually
inspected and independently reproduced byte for byte. The selected-path pilot
and scoped Ruff/Basedpyright pass. Shared villager templates remain component

```sh
uv run -m tools.view_item8_betterend_ruins --voyager-landmarks --output evidence/raw/item8/voyager-landmark-views-r1
```

is independently rescaled, and partial block models, hidden interiors and actual
world placement are not rendered. The farm and tree-monument bottom-row views
approach the sheet edge; some wide landmark views approach neighboring labels.
Use the full SVG title/path and preserved graph for attribution. Screen scale is
not a dimension measurement. Sheet groupings are comparison selections, not family
assignments or a natural/authored classification.
